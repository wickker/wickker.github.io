NanoClaw privacy policy

Last updated: 19 November 2026

NanoClaw is a personal app used only by its owner. It is not available to the public.

What data it uses

With the owner's consent through Google sign-in, NanoClaw reads, creates, updates and deletes events in the owner's Google Calendar, and reads the owner's basic Google profile (name and email address) to identify the connected account.

How the data is used and stored

Calendar data is used only to carry out the owner's own requests. Access tokens are stored only on the owner's computer. To understand and carry out a request, relevant calendar details may be processed by the AI model provider that powers NanoClaw (Anthropic). Data is never sold, shared for advertising, or used for any other purpose.

Google API Services User Data Policy

NanoClaw's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
